# Release notes

## 1.0.0

The first release brings together a native Compose weather app and an offline browser companion. Isfahan, Shiraz, Tehran and Tabriz have recorded public forecasts with source metadata, and foreground refresh keeps the last successful download available when a connection fails.

Six original landscape studies have animated day and night palettes. Clear skies include sunlight, moving cloud and water layers; night adds starlight and moonlight reflections. Studio blends between day and night, and reduced motion freezes the complete scene. Forecast views include temperature, precipitation, daily ranges and hour selection. Units and motion preferences persist locally. Android window timings and browser callback cadence can be inspected in separate reports.

The release includes source, tests, captured interface images and an optimized Android preview build. The preview uses a development signing certificate; release signing remains an owner-managed distribution step.
