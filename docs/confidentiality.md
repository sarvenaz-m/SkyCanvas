# Confidentiality and project boundary

SkyCanvas was written as a new, independent weather application. The repository contains the code, original illustrations and public forecast responses used by this implementation.

No employer repositories, private services, production credentials, customer information, internal documentation or restricted design assets were supplied or copied into it. Employer product names and private identifiers are not used in application data or network calls. Open-Meteo is the weather source; source and licence information travel with the recorded responses.

This boundary allows the project to demonstrate Android engineering without reproducing an employer's implementation. It does not assert employer endorsement, ownership of a past product, or a legal determination about the terms of a particular agreement. Any description of professional experience should keep this independent project distinct from work delivered under an employment contract or NDA.

The offline scene gallery uses original artwork. Verification fixtures are test inputs, and the forecasts shipped in the product are the public records listed in `data/provenance.json`.
